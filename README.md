# RIFT ID — ROV ID Store Mockup

Static UX/UI mockup for a Thai ROV game-account storefront.

## Live preview
https://rov-id-mockup-auto589643-3110s-projects.vercel.app

## Current mockup scope
- Store-owned inventory model
- Demo inventory: 100 IDs
- Member-required purchase flow (mock only)
- Login / register demo
- Search, filter and sort
- Product detail modal
- Payment flow toggle: Auto QR / Manual transfer + slip
- Delivery flow toggle: Instant / Admin verification
- Checkout mockup
- Contact placeholders
- Responsive desktop/mobile
- No database and no real payment connection

## Notes
This is a UX/UI prototype for client review. Production integrations (database, authentication, payment verification, account-delivery security, real branding/contact channels) are intentionally excluded from this version.
